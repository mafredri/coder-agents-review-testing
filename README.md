# coder-agents-review-testing

Test repository for end-to-end runs of
[coder-agents-review](https://github.com/coder/coder-agents-review). The
`coder-agents-review-testing` GitHub App is installed here only. Test pull
requests change the Go package in `ringbuf/`.

`modes.json` is a copy of the file in coder-agents-review; the bot reads it
from this repository when `MODES_REPO` points here.
